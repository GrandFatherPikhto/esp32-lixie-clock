# ESP32 Lixie Clock — Архитектура

Этот документ описывает структуру, модули и потоки данных прошивки часов в стиле Lixie (edge-lit) — для тех, кто хочет понять или расширить код. Как проект проверяется — см. [tests_ru.md](tests_ru.md).

## 1. Обзор

Часы — это **ESP32** под управлением **ESP-IDF** (рекомендуется **v6.0.2**, также собирается на v5.3). Управляется адресная лента WS2812 (10 светодиодов на цифру), время синхронизируется по **NTP через Wi-Fi**, а настройки меняются **в рантайме через USB-порт платы** (консоль UART0) — перепрошивка для настроек не нужна.

Ключевые свойства:

- **Чистая логика отделена от железа.** Всё, что можно тестировать на хосте, вынесено в `core/` **без зависимостей от ESP-IDF** (разбор/валидация конфигурации, математика времени, отрисовка цифр). Это главное архитектурное решение: один и тот же код валидации работает и в прошивке, и в host-юнит-тестах.
- **Прошивка не привязана к чипу.** Одна кодовая база собирается для `esp32`, `esp32s2`, `esp32s3`, `esp32c3`, `esp32c6`, `esp32h2`. Нужно выбрать только пин ленты WS2812 и целевой чип.
- **Рантайм-конфигурация.** Все рабочие параметры хранятся в NVS и меняются через последовательную консоль или помощник `configure_clock.py`.

## 2. Структура каталогов

| Путь | Назначение |
|------|------------|
| `main/` | Компонент прошивки ESP-IDF |
| `core/` | Чистая логика без ESP-IDF: `core_config`, `core_time`, `core_display` |
| `tools/` | Python-помощники: `configure_clock.py` (настройка по USB), `build_target.py` (сборка под разные чипы) |
| `tests/` | Набор pytest для Python-инструментов + `tests/c/` host C юнит-тесты (Unity) |
| `.github/workflows/ci.yml` | CI: python-инструменты, host C тесты, матрица сборок прошивки |
| `.devcontainer/` | Опциональный Docker devcontainer ESP-IDF |
| `config.yaml` | Единый источник настроек для устройства (также читает раздел `build:`) |

## 3. Карта модулей

| Модуль | Файлы | Назначение |
|--------|-------|------------|
| `core_config` | `core/include/core_config.h`, `core/src/core_config.c` | Структура `clock_config_t` + разбор `key=value` и проверка диапазонов (чистая, тестируется на хосте) |
| `core_time` | `core/include/core_time.h`, `core/src/core_time.c` | Математика UTC→локальные ч/м/с, строка часового пояса, проверка ночного окна `core_time_is_night_hour()` (чистая) |
| `core_display` | `core/include/core_display.h`, `core/src/core_display.c` | Размещение цифр→светодиоды и HSV→RGB (чистая) |
| `app_config` | `main/app_config.c`, `main/include/app_config.h` | Рантайм-конфигурация в NVS; `get`/`set`/`save`/`reset`/`dump`; геттеры; применение часового пояса |
| `config_console` | `main/config_console.c`, `main/include/config_console.h` | REPL-консоль ESP Console на UART0 (USB): `get`, `set`, `save`, `reset`, `reboot`, `status` |
| `wifi_manager` | `main/wifi_manager.c`, `main/include/wifi_manager.h` | Подключение STA/переподключение, ожидание IP, `wifi_manager_disconnect()` (выключение радио) |
| `sntp_sync` | `main/sntp_sync.c`, `main/include/sync_time.h` | Одноразовая / фоновая синхронизация SNTP; флаг `time_is_synced()` |
| `clock_ui` | `main/clock_ui.c`, `main/include/clock_ui.h` | Пофреймовый рендер с состоянием: загрузочная анимация, время, cross-fade, слот-машина, палитры, ночной режим, breathing |
| `led_display` | `main/led_display.c`, `main/include/led_display.h` | Инициализация RMT-канала и энкодера; `led_display_send()` для отправки буферов пикселей |
| `led_strip_encoder` | `main/led_strip_encoder.c`, `main/include/led_strip_encoder.h` | Специфичный для WS2812 RMT-энкодер |
| `main` | `main/main.c` | Запуск, задачи FreeRTOS, аппаратный таймер дисплея |

## 4. Цепочка рантайм-конфигурации

Параметр, например `brightness`, проходит один хорошо определённый путь:

1. **Ввод** — `configure_clock.py set brightness=50 save` (по USB) отправляет `set brightness=50` в консоль; `configure_clock.py apply` читает `config.yaml`.
2. **Разбор и валидация** — команда `set` вызывает `app_config_set()` → `core_config_set_value()`, который преобразует строку и проверяет диапазоны (например, `night_low_brightness` 0..100, `cross_fade` 0..2000 мс).
3. **Хранение** — `app_config_save()` записывает всю структуру `clock_config_t` одним blob'ом в NVS.
4. **Чтение** — модули используют геттеры `app_config_get_*()` каждый кадр или цикл.

Поскольку разбор/валидация живут в `core/`, они покрываются юнит-тестами на хосте без устройства.

## 5. Рендер дисплея (`clock_ui`)

[`clock_ui_frame(pixels, time_synced)`](../main/clock_ui.c) — пофреймовый рендер с состоянием, который запускается display-задачей на ~33 fps (таймер 30 мс):

- **До синхронизации** — загрузочная анимация: прокрутка цифр 0–9 со сменой цвета.
- **После синхронизации** — текущее время (локальные ч/м/с из `core_time_utc_to_hms()`), цвет по активной палитре.
- **Cross-fade** — смена цифр плавно затухает/загорается за `cross_fade` миллисекунд (0 = мгновенно); старая и новая цифры используют одни и те же 10 светодиодов с дополняющей яркостью.
- **Слот-машина** — периодическая прокрутка 0–9 (≈2,5 с) каждые `slot_machine_interval` минут (0 = выкл), идёт через тот же механизм cross-fade.
- **Ночной режим** — снижает яркость до `night_low_brightness` в окне `night_start`..`night_end` (с переносом через полночь), когда `night_mode` включён.
- **Breathing** — опциональная пульсация яркости, сочетается с любой палитрой.

Вся анимация **основана на времени** (накопители по 500 мс для классических скоростей палитр/загрузки), поэтому частота кадров не влияет на скорость. Цвет считается в `palette_hue()`, которая принимает режим палитры, глобальный сдвиг `hue_shift` и дополнительный оттенок `hue_2` (двухцветный Mono).

## 6. Задачи и тайминг

- **`sync_task`** (приоритет 5) — подключает Wi-Fi и вызывает `init_sntp()`. При успехе либо завершается (по умолчанию), либо при `wifi_power_save` выключает радио и спит `sync_interval` секунд до следующего ресинка. При неудаче повторяет каждые 10 с.
- **`display_task`** (приоритет 4) — владеет буфером пикселей. Вместо `vTaskDelay` периодический `esp_timer` (30 мс) будит задачу из ISR; при каждом пробуждении рендерится кадр через `clock_ui_frame()` и отправляется через `led_display_send()` (RMT остаётся в контексте задачи).

## 7. Wi-Fi / NTP / энергосбережение

- `wifi_manager` подключается по рантайм SSID/паролю, авто-переподключается при обрыве и ждёт IP (таймаут 20 с).
- `init_sntp()` запускает SNTP-клиент с рантайм-сервером, интервалом и методом синхронизации (мгновенно или плавно `adjtime`). При **выключенном power save** (по умолчанию) клиент остаётся запущенным, и фоновый SNTP держит время при подключённом Wi-Fi. При `wifi_power_save = 1` синхронизация одноразовая, SNTP-клиент останавливается, а `sync_task` вызывает `wifi_manager_disconnect()` (радио полностью выключено) до следующего `sync_interval`; дисплей продолжает работать от времени libc на основе RTC.
- USB-консоль и `configure_clock.py` работают по UART и не зависят от состояния Wi-Fi.

## 8. Инструменты (`tools/`)

- **`configure_clock.py`** — управляет последовательной консолью по USB: `get`, `set`, `save`, `reset`, `reboot`, `status`, `apply` (из YAML). Автоопределение порта по числовым VID/PID (CP210x/CH340/FTDI), затем по описанию. Маскирует пароль Wi-Fi в выводе.
- **`build_target.py`** — обёртка над `idf.py set-target` + `build` (+ опционально `menuconfig`/`flash`/`monitor`/`clean`) для любого поддерживаемого чипа; читает раздел `build:` из `config.yaml`.

## 9. Тесты и CI

- **Уровень 1 — Python-инструменты:** набор pytest в `tests/` (без платы; порт и YAML мокаются).
- **Уровень 2 — Host C юнит-тесты:** Unity-тесты для `core/`, запускаются нативно на Linux/WSL через `tests/c/run_tests.sh`.
- **Уровень 3 — Сборки прошивки:** `idf.py` сборки всех шести целей, выполняются в CI на Ubuntu при каждом пуше / pull request.

Настройку и запуск каждого уровня локально (Windows и Linux/WSL) см. в [tests_ru.md](tests_ru.md).

## 10. Основные функции

| Функция | Описание |
|---------|----------|
| `app_config_init()` | Загрузить конфигурацию из NVS (или по умолчанию) и применить часовой пояс |
| `app_config_set()/save()/reset()` | Изменить, сохранить, сбросить рантайм-конфигурацию |
| `core_config_set_value()` | Разобрать/проверить один `key=value` для `clock_config_t` (чистая) |
| `core_time_is_night_hour()` | Проверка ночного окна с переносом через полночь (чистая) |
| `config_console_init()` | Запустить REPL последовательной консоли |
| `wifi_manager_connect()` | Подключиться к настроенной Wi-Fi и ждать IP |
| `wifi_manager_disconnect()` | Остановить радио Wi-Fi (`esp_wifi_stop()`) |
| `init_sntp()` | Подключиться, запустить SNTP, дождаться первой синхронизации; возвращает успех |
| `time_is_synced()` | `true` только после успешной синхронизации времени |
| `clock_ui_frame()` | Отрисовать один кадр (загрузка/время/cross-fade/слот/ночь) |
| `led_display_send(pixels, size)` | Отправить массив пикселей на ленту (ограниченное ожидание) |
